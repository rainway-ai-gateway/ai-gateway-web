# 14 附录

## A. 术语表

| 术语 | 说明 |
| ------ | ------ |
| 数据面 / BFE | 接收并转发请求的引擎，执行鉴权、限流、配额、路由 |
| 控制台 | Web 管理界面（本文档对象） |
| 实例池（服务商） | 模型服务商中登记的后端实例清单：IP 模式为「IP + 端口 + 权重」多行，服务商域名模式为单个域名；实例池归属服务商，集群通过「所属服务商」引用，见 [3.4 节](03-model-provider.md#34-实例池) |
| 模型服务商 | 持有后端实例池、模型协议、模型列表与服务鉴权 Key 明文的资源；集群通过「所属服务商」引用 |
| 业务集群 | 引用服务商，配置协议 / 超时 / 健康检查 / 转发模型与 Key 权重等转发策略 |
| 负载均衡模式（`balance_mode`） | `WRR` 由 BFE 本地加权轮询选择后端；`EPP` 由 EPP 调度器接管后端选择 |
| EPP 调度器（Endpoint Picker） | 独立于 BFE 的后端调度器，按「集群 ↔ 实例组」分配后端，见 [5.1 节](05-epp-schedule.md#51-epp-实例池) |
| 均衡模式配置 | 集群向导第 4 步中设置 `balance_mode` 与 `epp_config` 的卡片，见 [4.6 节](04-ai-business-cluster.md#均衡模式配置) |
| 实例负载画像（`load_profile`） | EPP 选后端时的偏向：`queue-first`（排队优先）/ `balanced`（均衡，默认）/ `kv-first`（KV 空闲优先） |
| 亲和强度（`affinity`） | 把同前缀 / 同会话请求聚到同一后端的力度：`off` / `low`(0.3) / `medium`(0.6，默认) / `high`(1.0) |
| EPP 运行时参数（`epp_runtime`） | BFE 访问 EPP 的健康检查（`check`）与超时（`timeout`）参数，未配置时由 BFE 补默认，见 [4.6 节](04-ai-business-cluster.md#epp-运行时参数) |
| 时长（Go duration） | 如 `2s`、`500ms`、`1m30s`，须为大于 0 的合法时长；界面上以「数字 + 单位（ms / s / m）」输入 |
| Entity | 调用方分组（组织），挂载配额 / 限流 / 模型访问控制 |
| Entity 类型 | 组织层级定义（级别数字越小层级越高） |
| API Key | 调用凭证，请求头 `Authorization: <Key>`（不需要 Bearer 前缀） |
| 批量任务 | 经数据面透传创建的 provider 原生批量任务（OpenAI Batch API），控制台只做列表 / 详情 / 取消，见 [19.1 节](19-batch-tasks.md#191-列表页) |
| 预留金额 / 结算金额 | 批量任务的 `reserve_units` / `settle_units`，1e-8 定点整数、单位 RMB，界面原样展示不换算，见 [19.4 节](19-batch-tasks.md#194-状态与金额口径) |
| 终态 | 批量任务的 `completed` / `expired` / `failed` / `cancelled`，进入终态后不可取消，见 [19.4 节](19-batch-tasks.md#194-状态与金额口径) |
| 路由表 | Global / Entity / API-Key 三级，优先级依次升高 |
| 首条命中生效 | 集合级规则按数组顺序匹配，命中首条即停止，数组顺序即优先级 |
| AI缓存规则 | 集合级应答缓存配置（缓存规则 + 语义设置两个页签），见 [15.1 节](15-ai-cache-rules.md#151-页面构成与规则列表) |
| 缓存键策略 | 决定缓存键取哪部分内容：`lastQuestion`（默认）/ `allQuestions` / `disabled`，见 [15.3 节](15-ai-cache-rules.md#153-添加--编辑缓存规则) |
| 缓存豁免（`disabled`） | 数据面显式不缓存且阻断后续规则，与「从规则集合删除」语义不同，见 [15.8 节](15-ai-cache-rules.md#158-注意事项) |
| 流量镜像 | 把生产请求副本异步发往镜像集群，副本响应丢弃、仅入统计（不扣配额、不计用量），见 [16 章](16-traffic-mirror-rules.md) |
| 意图分类 | 数据面判定请求的「问题 → 答案」，供路由条件 `req_ai_intent_in(...)` 匹配，见 [17.9 节](17-intent-config.md#179-运行时生效机制) |
| 置信度门控阈值（`min_confidence`） | 答案置信度低于该值时视为 `unknown`（全局阈值可被单问题覆盖），见 [17.3 节](17-intent-config.md#173-全局配置最小置信度) |
| AI上下文压缩 | 按生效条件对命中请求裁剪 / 改写 prompt，降低 token 成本，见 [18.1 节](18-ai-context.md#181-压缩规则列表) |
| 压缩档位 | `off`（不处理）/ `conservative`（仅无损裁剪）/ `balanced`（裁剪 + lite 改写）/ `aggressive`（裁剪 + full 改写），见 [18.1 节](18-ai-context.md#181-压缩规则列表) |
| TPM | Tokens Per Minute，滑动窗口 Token 限流 |
| RPM | Requests Per Minute，固定窗口请求限流 |
| 配额 | 周期内 Token 或金额总量控制，不足拒绝并回滚已扣部分 |
| 会话保持 | 同一客户端请求稳定落到同一后端实例（哈希策略） |
| 备用集群 / fallbacks | 路由规则中目标集群失败时的回落目标 |
| 转发模型 | 集群从大模型配置中选择的、允许转发的模型子集 |
| Key 路由策略 | 多 Key 的轮询与重试策略 |
| Key 亲和性 | 同一会话绑定同一 Key，需 Redis 支持 |
| 分段计价 / peak | 服务商忙时时间段，用于模型定价分时段价格匹配 |
| 模型定价 | 模型价格信息维护，用于费用核算 |
| 批量折扣系数（`batch_discount`） | 非批量价格行的批量价折扣，取值 `(0,1]`、默认 `0.5`；导出时把各 Token 价格键 × 系数展开生成 `(provider, model, mode=batch)` 价格行，见 [6.2 节](06-model-prices.md#批量折扣系数) |
| 证书 / 全局缺省证书 | HTTPS 接入所用 PEM 证书；全局有且仅有一个默认证书 |
| 密钥收敛（Reencrypt Sweep） | 把库内敏感密钥列批量重写为当前活跃密钥密文的异步任务，见 [20.1 节](20-key-reencrypt.md#201-触发收敛任务) |
| 预演模式（`dry_run`） | 只扫描统计、不写库，`rewritten` 表示「将要重写」的行数，见 [20.4 节](20-key-reencrypt.md#204-任务详情) |
| 操作日志 | 平台写操作的只读审计记录，含变更摘要与请求上下文 |
| 数据报表 | 运营数据可视化模块，提供总览指标、时序图表、维度排行与日志明细查询 |

## B. 常见错误提示对照

| 提示 / 现象 | 含义 | 处理 |
| ------ | ------ | ------ |
| 数据重复 | 同名记录已存在（服务商 / 集群 / 类型 / 组织 / 规则等） | 换名或先删除旧记录 |
| 删除失败，该服务商可能仍被集群引用 | 服务商仍被业务集群使用 | 先修改或删除引用集群 |
| 参数非法 exec-api … connection refused | 模型发现接口不可达 | 检查服务商实例池地址 / 端口 / 网络 |
| 权重之和必须等于100 | 规则目标或 Key 权重校验失败 | 调整权重使和为 100 |
| 目标集群和模型组合不能重复 | 同一规则内目标重复 | 删除重复目标 |
| 备用集群和模型组合不能重复 | 备用与目标重复 | 删除重复项 |
| `epp_runtime is invalid: json: unknown field "breaker"`（或 `"tls"`） | 提交集群时携带了不对用户开放的 `epp_runtime.tls` / `epp_runtime.breaker`（返回 422） | 删除这两个字段后重试；`EPPTLS`（明文）、`EPPBreaker`（关闭熔断）由后端固定下发，见 [4.6 节](04-ai-business-cluster.md#epp-运行时参数) |
| 均衡模式选 `EPP` 却未带 `epp_config`（返回 422） | `balance_mode=EPP` 时 `epp_config` 必填 | 在「均衡模式配置」卡片补全后提交；或把模式改回 `WRR`，见 [4.6 节](04-ai-business-cluster.md#均衡模式配置) |
| 健康检查间隔须为合法的 Go duration 且 > 0（如 2s） | 时长 / 单位不合法，或填了 `0`（`0` 会被拦截，不会静默变成默认值） | 填大于 0 的合法时长（如 `2s`）；清空表示未设置，由 BFE 补默认，见 [4.6 节](04-ai-business-cluster.md#epp-运行时参数) |
| 哈希头部必填 | 哈希策略为 CLIENT_ID_* 但未填头部 | 填写如 `x-client-id` 或 `Cookie:USERID` |
| 规则名称已存在，集合内必须唯一 | AI缓存规则 / 流量镜像规则提交前做集合内规则名查重，发现重名 | 改名后重新「提交并生效」，见 [15.2 节](15-ai-cache-rules.md#152-视图--编辑双模式与提交并生效) |
| 生效条件重复，集合内必须唯一（流量镜像）／生效条件已存在，集合内必须唯一（AI上下文压缩） | 同一集合内两条规则的生效条件表达式重复 | 修改其中一条条件或删除重复项后提交，见 [16.2 节](16-traffic-mirror-rules.md#162-视图--编辑双模式与提交并生效)、[18.5 节](18-ai-context.md#185-提交并生效) |
| 自定义剔除列表不能为空 | 流量镜像选了「自定义剔除列表」但未填任何 Header | 填入逗号分隔的 Header 名，或改选「使用默认黑名单」/「不剔除任何头部」，见 [16.6 节](16-traffic-mirror-rules.md#166-字段校验与错误提示) |
| 问题名称已存在，必须全局唯一 ／ 选项名不能包含 \| | 意图配置中问题名重复，或 `choice` 选项名含竖线（数据面按 \| 拼接选项） | 改名 / 去掉竖线后重新「保存并发布」，见 [17.8 节](17-intent-config.md#178-校验规则与提示文案) |
| 最小置信度必须为 0-1 | 意图配置的全局门控阈值或单问题覆盖值越界、非数字 | 填 0–1 之间的数值（步进 0.01），见 [17.3 节](17-intent-config.md#173-全局配置最小置信度) |
| 提交失败! | AI缓存规则 / 流量镜像规则 / 意图配置 / AI上下文压缩的提交请求失败（含后端校验不通过） | 先按页面内的校验提示修正再重试；仍失败时见 [11 章 操作日志](11-operation-logs.md) 按资源类型核对请求 |
| 401 | Key 错误 / 过期 / IP 不在允许子网 | API Key 管理核对 |
| 403 | 模型不在允许列表或在禁止列表 | 核对 Key / 组织允许模型，见 [8.5 节](08-entity.md#85-模型访问控制) |
| 429 | 触发 TPM / RPM 限流 | 调整限流规则，见 [8.6 节](08-entity.md#86-运行时生效机制) |
| 配额错误 | 配额余额不足 | 查看余量或重置配额 |
| 任务已进入终态或正在被其它实例处理，取消未生效 ／ 批量任务不存在或已被清理 | 取消批量任务时返回 409（任务已终态或他实例抢占）或 404（任务 DB 与 Redis 均未命中） | 刷新列表以服务端状态为准；404 时确认任务是否已被清理，见 [19.3 节](19-batch-tasks.md#193-取消批量任务) |
| 已有任务运行中，task_id: {id}，请等待完成 | 密钥收敛为集群级单例，已有任务运行时再次触发（409），页面不排队 | 等待该 task_id 完成，或直接轮询该任务，见 [20.1 节](20-key-reencrypt.md#201-触发收敛任务) |
| 错误：executor lost | 密钥收敛任务详情的红色告警条：执行实例失联，任务被接管并标记为失败 | 重新触发一次任务即可自动接管收敛，见 [20.5 节](20-key-reencrypt.md#205-注意事项) |
| Feature Access Deny | 无操作日志读权限 | 系统管理员与系统管理员（只读）均可访问；无读权限时联系管理员确认账号角色，见 [11.4 节](11-operation-logs.md#114-权限说明) |
| 批量折扣系数必须为 (0,1] 区间内的浮点数 | 模型定价「批量折扣系数」填了 `0`、负数或大于 `1` 的值 | 填 `(0,1]` 区间内的浮点数（如 `0.5`）；`mode=batch` 的价格行不渲染该输入，见 [6.2 节](06-model-prices.md#批量折扣系数) |
