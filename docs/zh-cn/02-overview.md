# 02 概览：控制台布局与导航

登录成功后进入控制台，整体布局为「左侧导航 + 右侧内容区」。首次使用建议先浏览本章，再跟做 [13 场景实战](13-scenarios.md)。

## 2.1 导航结构

```text
AI 网关
├─ 资源管理
│   ├─ AI业务集群        引用服务商，配置转发策略
│   ├─ 模型定价           模型价格维护与费用核算
│   ├─ 模型服务商          实例池、协议、模型与 Keys
│   └─ EPP调度            EPP 实例池与集群调度分配
│
├─ 路由管理
│   └─ 路由表            Global / Entity / API-Key 路由规则
├─ 功能增强
│   ├─ AI缓存规则        应答缓存开关与缓存键规则
│   ├─ 流量镜像规则       生产请求副本异步发往镜像集群
│   ├─ 意图配置          问题集与置信度门控阈值
│   └─ AI上下文压缩       压缩规则与全局设置
│
├─ 消费者管理
│   ├─ API Key 管理      调用凭证签发与治理
│   ├─ 批量任务          provider 原生批量任务的管控
│   └─ Entity管理       类型 / 组织（配额、限流、模型访问控制）
│
├─ 系统安全
│   └─ 密钥收敛          库内敏感密钥的批量重加密 / 解密
│
├─ 数据报表              运营数据可视化：总览指标、图表与日志明细
├─ 用户管理              控制台账号与 Token（管理员）
└─ 操作日志              写操作审计查询（管理员）
```

## 2.2 通用交互约定

- **列表页**：搜索区 + 操作按钮 + 表格 + 分页；多数列表为前端分页、支持「20 条/页」切换；模型定价为服务端分页，默认 50 条/页，可切换 20 / 50 / 100 / 200 / 500 / 1000 条/页，操作日志与数据报表明细默认 20 条/页；
- **卡片**：配置项 / 字段组以卡片分区呈现，卡片标题仅作分组说明，不承担操作入口；
- **卡片折叠**：当前版本的卡片不提供折叠交互（标题不可点击展开 / 收起），卡片内容始终展开显示；
- **抽屉表单**：创建 / 编辑在右侧抽屉完成，底部「提交 / 取消」（向导类为「下一步 / 上一步」）；
- **编辑模式**：路由规则等高风险配置需先「进入编辑模式」，改完「本地保存」，再点「提交并生效」（提交后自动退出编辑模式），未提交的修改不影响线上流量；
- **通知**：操作结果以右上角通知呈现；错误通知（如「数据重复」）不自动消失，点 × 关闭。

## 2.3 三级路由优先级

请求进入数据面后按 **API-Key > Entity > Global** 顺序匹配路由表：先查该 Key 的专属表，未命中再查 Key 挂载组织的表，最后回落 Global。详见 [10 章](10-route.md)。
