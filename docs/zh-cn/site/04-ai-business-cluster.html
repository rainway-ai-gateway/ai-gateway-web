04 资源管理：AI 业务集群

业务集群是流量转发与治理策略在网关内的抽象：在已创建的模型服务商之上，配置协议、会话保持、超时重试、被动健康检查，并选择转发模型与 Key 权重。路由规则的目标即为「集群 + 模型」，请求经集群转发到所属服务商的实例池。

前置条件：须先在 03 章 模型服务商 中创建好服务商（实例池、协议、模型、Keys），再在集群向导中选择「所属服务商」。

向导步骤必填项
1 基础配置集群名称、协议（http / https，与后端实际一致）
4 大模型配置所属服务商、转发模型（至少 1 个）；多 Key 时配置权重
2 / 3 / 5保持默认，直接下一步

4.1 集群列表

点击「详情」，右侧弹出抽屉，以只读方式展示全部配置（基础配置、超时和重传、被动健康检查、大模型配置），与 4.7 步骤 5：复查&检查 汇总面板一致。不展示服务商实例池（实例池归属服务商资源）。

删除集群

4.2 创建 / 编辑集群

点击「添加集群」，右侧弹出 5 步向导：

  1. 基础配置 → 2. 超时和重传 → 3. 被动健康检查 → 4. 大模型配置 → 5. 复查&检查

与 0.0.7 及更早版本的区别：向导已移除「实例配置」步骤；实例池改在模型服务商模块维护。

编辑已有集群时，同样抽屉以编辑模式打开，字段预填充。集群名称创建后不可修改。

4.6 步骤 4：大模型配置

选择所属服务商后，系统加载该服务商的模型列表与 Key 名称，集群侧只配置选用哪些模型、各 Key 权重及转发策略。

模型重定向

将客户端请求的模型名映射为转发到后端的模型名。选择「转发的后端模型名称」后，若「原请求的模型名称」为空，会自动填入同名，之后仍可修改。原模型名不能重复；目标模型须从「转发模型」已选项中选择。

与 API-Key 允许/禁止模型的组合：Key 的模型访问控制按重定向后的目标模型判定。例如原模型名 glm-5.2-abc、目标模型 glm-5.2 时，Key 允许模型配置 glm-5.2 即可放行客户端发送的 model=glm-5.2-abc 请求（详见 9.7 运行时生效机制）。

服务鉴权 Keys

字段必填说明

权重条件必填0-100；有配置 Key 时所有行权重之和须等于 100
  • 非必填：不配置时由网关按服务商 Keys 默认策略处理。
  • 空行不参与校验；有值的 Key 名称须属于所选服务商。

EPP 运行时参数

选择 EPP 时，除 epp_config 外，还可配置 BFE 访问 EPP 调度器时的健康检查与调用超时参数（epp_runtime）；不配置时由 BFE 补默认值。

健康检查（check）：

字段必填默认值校验规则说明
关闭后台健康检查否停用布尔启用后 BFE 不再对 EPP 端点做主动健康检查；不建议生产关闭
健康检查间隔否2s合法且大于 0 的时长两次探测的间隔
失败次数阈值否3整数且 ≥ 1连续失败达到该值判定端点不健康
冷却时长否45s合法且大于 0 的时长端点被判定不健康后的冷却时间
成功次数阈值否2整数且 ≥ 1连续探测成功达到该值恢复为健康

调用超时（timeout）：

字段必填默认值校验规则说明
连接超时否500ms合法且大于 0 的时长与 EPP 建连超时
调用超时否3s合法且大于 0 的时长单次调用 EPP 的超时

时长字段的输入控件：

  • 健康检查间隔、冷却时长、连接超时、调用超时这 4 个字段是「数字框 + 单位下拉（ms / s / m）」复合控件；健康检查间隔、冷却时长、调用超时默认单位为 s，连接超时默认单位为 ms。
  • 切换单位时会换算数值、保持物理时长不变（500ms 切到 s 显示 0.5s）。
  • 存量值若为无法拆分的组合写法（如 1m30s），该字段回退为纯文本输入框并原样展示，不做换算。
  • 校验：须为大于 0 的合法 Go duration（+1s、1.s、.5s 等写法合法）；填 0 会在提交时被拦截报错，不会静默回落为默认值；清空数字框表示未设置，提交时按默认值补齐。
  • tls 与 breaker 不对外暴露：由后端固定下发（EPPTLS 为明文、EPPBreaker 关闭），界面不提供配置入口。
  • 未配置时展示为「未配置（BFE 补默认）」，由 BFE 按上表默认值运行，与「已落盘一组默认值」不同。
  • 7 个字段中只有 3 个带 ? 提示图标：关闭后台健康检查、冷却时长、调用超时；其余字段无提示。

WRR ↔ EPP 切换：epp_config 与 epp_runtime 仅在 EPP 模式下生效；切回 WRR 时配置保留但不生效（休眠），再切回 EPP 继续生效，来回切换不丢配置。

4.8 注意事项

  • 集群名称创建后不可修改。
  • 修改集群会影响所有引用该集群的路由规则，建议低峰期操作。
  • 健康检查 Host 留空时，使用所属服务商实例池首个实例地址。
  • 转发模型必须是所属服务商模型列表的子集；更换服务商后须重新选择模型与 Keys。
  • 删除集群前须解除路由规则引用。
  • 只读管理员登录时，本模块的「添加集群」按钮、列表操作列的「编辑」「删除」以及向导页脚的「提交」按钮均不显示，仅保留「详情」与向导的只读查看。
  • EPP 模式集群的后端选择由 EPP 调度器接管；若实例池中无有效分配（未分配态），该集群导出配置时会降级为 WRR。分配关系在「EPP调度」页查看与覆写，见 05 章。
